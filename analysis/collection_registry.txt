# Which collections under output/ count as evaluation data.
#
# This lives in the repo rather than beside the data: output/ is gitignored, so
# a marker file there would vanish on a fresh clone and could never be reviewed
# in a diff. Deciding what counts as evidence is a judgement, and judgements
# belong in version control.
#
# Format:  <verb> <glob> <category> [# note]
#   exclude — keep out of cross-collection analysis
#   include — force back in, overriding any exclude below it
#
# Globs match the directory name (fnmatch). Includes win over excludes, so a
# specific include can carve one volume out of a broad exclude.
#
# Collections matching nothing are INCLUDED: production is the norm, and a new
# volume should not silently disappear from an evaluation because nobody
# remembered to register it. Tools print what they excluded, so the reverse
# mistake stays visible — an unnoticed 6,862-file backup directory is how a
# cross-collection table got polluted in the first place.
